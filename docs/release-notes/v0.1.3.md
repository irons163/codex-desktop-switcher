# Codex Account Switcher 0.1.3

## 繁體中文

修正同一信箱的一般帳號與企業工作區在加入時互相覆蓋的問題。

- 儲存與去重改為比對帳號及選定的工作區 ID，同一信箱可以保留個人與多個企業工作區。
- 重新登入同一工作區或更新登入憑證時，會更新原快照，不會產生重複項目。
- 個人選單、帳號設定頁與切換器會顯示方案與工作區識別碼；顯示文字相同時另加快照名稱。
- 手動儲存時，若名稱已屬於另一帳號或工作區，會要求使用其他名稱，保留既有快照。
- 舊快照缺少工作區 ID 時，會與已知工作區分開保留，避免因信箱相同而覆蓋。

請關閉舊切換器，更新後按「啟動」，再分別加入個人與企業工作區。
舊版已覆蓋的登入資料無法由此次更新重建，需要重新登入加入。

## English

Fixes personal and business workspaces sharing an email overwriting each other when added.

- Match saved accounts by user and selected workspace ID, preserving personal and multiple business workspaces for one email.
- Update the existing snapshot when signing in again or refreshing credentials for the same workspace.
- Show the plan and workspace identifier in the profile menu, account settings, and switcher. Add the snapshot name when labels would otherwise be identical.
- Refuse manual saves that would replace another account or workspace using the same snapshot name.
- Keep legacy snapshots with unknown workspace IDs separate from known workspaces.

Quit the old switcher, update, click **Launch**, and add personal and business workspaces separately.
Credentials overwritten by older versions cannot be reconstructed by this update; sign in to add them again.

Apple Silicon and Intel installers are signed with Developer ID and notarized by Apple.
