# Codex Account Switcher 0.1.1

The first published macOS release of Codex Account Switcher, including the
security fixes completed before making the repository public.

- Save multiple Codex accounts and switch from the profile menu or Accounts settings page.
- Relaunch Codex when switching accounts so the selected login takes effect.
- Support the unified ChatGPT desktop app and 65 interface locales.
- Wait up to 60 seconds for launch and injection instead of reporting an early timeout.
- Reject cross-site bridge requests, DNS-rebinding hosts, and commands from untrusted frames.
- Store credentials in private directories and replace authentication files atomically with owner-only permissions.
- Restrict sign-in destinations to official OpenAI HTTPS URLs and asset discovery to bundled app resources.

The switcher injects its account interface at runtime and does not modify or
re-sign the installed Codex or ChatGPT app.

## Downloads and requirements

Choose `apple-silicon.dmg` for Apple Silicon Macs or `intel.dmg` for Intel Macs,
then drag Codex Account Switcher into Applications. Both installers are signed
with Developer ID and notarized by Apple. `SHA256SUMS` lists checksums;
`.dSYM.zip` files are optional debugging symbols.

Requires macOS 13 or later and an installed Codex or compatible ChatGPT desktop
app. Node.js 22 or later must be available if the desktop app does not bundle it.
