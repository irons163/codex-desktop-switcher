# Codex Account Switcher 0.1.0

The first macOS release of Codex Account Switcher.

- Save multiple Codex accounts and switch between them from the Codex profile menu or Accounts settings page.
- Relaunch Codex when switching accounts so the selected login takes effect.
- Launch the current Codex desktop app, including the unified ChatGPT app, with a local account bridge.
- Support 65 interface locales and automatically follow the system language.
- Wait up to 60 seconds for launch and injection, avoiding premature timeout errors during a restart.
- Reject cross-site bridge commands and untrusted frames, keep authentication files private, and restrict sign-in links to official OpenAI HTTPS URLs.

The switcher injects its account interface at runtime and does not modify or re-sign the installed Codex or ChatGPT app.

## Downloads and requirements

Choose `apple-silicon.dmg` for Apple Silicon Macs or `intel.dmg` for Intel Macs, then drag Codex Account Switcher into Applications. Both installers are signed with Developer ID and notarized by Apple. `SHA256SUMS` lists checksums; `.dSYM.zip` files are optional debugging symbols.

Requires macOS 13 or later and an installed Codex or compatible ChatGPT desktop app. Node.js 22 or later must be available if the desktop app does not bundle Node.js.
