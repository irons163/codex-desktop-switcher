# Codex Account Switcher 0.1.2

## 繁體中文

修正按下「新增登入」後，停留在「正在開啟可選帳號登入…」的問題。

- 改由 Codex 內附的登入服務產生官方登入網址，不再依賴會隨桌面程式更新而變動的內部網頁模組。
- 先儲存目前帳號，並保留目前登入資料；瀏覽器開啟失敗或逾時時，可以直接重試。
- 新帳號登入成功後，自動儲存帳號並重新啟動 Codex。
- 加上登入服務、開啟瀏覽器與等待登入的逾時處理。選單會顯示錯誤，並恢復按鈕。
- 停止 bridge 或切換帳號時，會取消尚未完成的新增登入。
- 啟動新版切換器時，會自動替換仍在執行的舊版 bridge，讓修正立即生效。

## English

Fixes New sign-in getting stuck on “Opening account chooser sign-in…”.

- Use the desktop app's bundled Codex sign-in service instead of importing private web modules that change between app versions.
- Save the current account and keep its active credentials in place until the new account signs in successfully.
- Automatically save the new account and restart Codex when sign-in completes.
- Bound service startup, browser opening, and login waiting with timeouts; show errors in the menu and re-enable its buttons for retry.
- Cancel pending sign-in when switching accounts or stopping the bridge.
- Replace older running bridge versions when launching the updated switcher.

Apple Silicon and Intel installers are signed with Developer ID and notarized by Apple.
